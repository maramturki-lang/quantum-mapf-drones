# Quantum-Assisted Multi-Agent Pathfinding for Autonomous Drone Swarms

Coordinating several autonomous drones on a shared 2D grid so that every drone reaches its target **without collisions**, while keeping travel distance and mission time low. The project compares a classical coordination method with a **QUBO formulation** solved by simulated annealing, which is a quantum-inspired approach.

Author: Maram Turki (ENIT, Tunisia)

---

## 1. Problem

| Element | Model used |
|---|---|
| Environment | 2D grid (10×10 or 20×20) with static obstacles (15 % density), 4-connected |
| Agents | Each drone has a start cell and a target cell, all distinct |
| Movement | At each time step a drone moves up, down, left or right, or **waits** |
| Communication | Centralised: the coordinator knows every planned path |
| Vertex conflict | Two drones occupy the same cell at the same time |
| Edge conflict | Two drones swap cells between `t` and `t+1` |

Main challenges include collisions, congestion in narrow passages, conflicting paths and scalability. The joint search space grows as `cells^agents`, and optimal MAPF is NP-hard.

## 2. Approach

| Strategy | File | Idea |
|---|---|---|
| **Independent A\*** (baseline) | `src/planner.py` | Each drone plans its shortest path alone, with no coordination |
| **Prioritized space-time A\*** | `src/coordinator.py` | Drones are planned one by one. A reservation table stores `(cell, t)` and edges already used. The search runs in `(x, y, t)` and may wait |
| **QUBO + simulated annealing** | `src/qubo_solver.py` | Candidate paths are generated per drone. A QUBO selects one path per drone that minimises cost and conflicts |

QUBO formulation (`x[i,k] = 1` if drone `i` uses candidate path `k`):

```
H(x) = Σ cost(i,k)·x[i,k] + A·Σ_i (1 − Σ_k x[i,k])² + B·Σ conflicts(i,k; j,l)·x[i,k]·x[j,l]
```

All strategies share the same interface `solve(agents)`, so they are compared with identical code (`src/simulation.py`) on identical scenarios.

## 5. Usage

**Run the tests**

```bash
python -m pytest -v               # 16 passed
```

**Quick demo**

```bash
python -c "
from src.environment import ScenarioGenerator
from src.coordinator import IndependentPlanner, PrioritizedPlanner
from src.qubo_solver import QUBOPlanner
from src.simulation import Simulation
grid, agents = ScenarioGenerator(10, 10, 0.15, seed=3).generate(5)
for P in [IndependentPlanner, PrioritizedPlanner, QUBOPlanner]:
    print(Simulation(grid, agents, P).run())
"
```

**Reproduce all results.** Open the notebooks and run them in order (*Kernel → Restart & Run All*):

```bash
python -m notebook notebooks/
```

### Dataset

No external dataset is needed. Environments are generated by `ScenarioGenerator(width, height, obstacle_ratio, seed)`. The same seed always gives the same grid, starts and targets. The generator also checks with BFS that every target is reachable. The [Moving AI MAPF benchmarks](https://movingai.com/benchmarks/mapf.html) could be plugged in as a future extension.

## 6. Results

### Scenario 1 (2 drones) and Scenario 2 (5 drones): 10×10 grid, mean over 50 instances

| Metric | S1 Independent | S1 Prioritized | S2 Independent | S2 Prioritized |
|---|---|---|---|---|
| Total travel distance | 14.32 | 14.44 | 34.66 | 36.02 |
| Conflicts | 0.10 | **0** | 1.38 | **0** |
| Conflict-free instances | 92 % | 100 % | 28 % | 100 % |
| Drones reaching target | 100 % | 100 % | 100 % | 100 % |
| Mission time (makespan, steps) | 9.00 | 9.00 | 10.88 | 11.12 |
| Execution time | 0.10 ms | 0.23 ms | 0.31 ms | 0.57 ms |

Without coordination, 72 % of the 5-drone missions contain at least one collision, even though every drone "reaches" its target. Prioritized planning removes all conflicts for about +4 % distance and +2 % mission time.

### Quantum-inspired extension: 5 drones, 20 instances

| Strategy | Conflicts | Sum of costs | Time |
|---|---|---|---|
| Prioritized A\* (classical) | 0 | 38.55 | 0.65 ms |
| QUBO, exact solver | 0 | **36.75** | 43 ms |
| QUBO, simulated annealing | 0 | 39.05 | 120 ms |

Global path selection (QUBO, exact) finds cheaper solutions than prioritized planning, because it decides for all drones at once with no arbitrary priority order. Simulated annealing finds valid, conflict-free solutions, but they are approximate. The model needs about 30 binary variables (qubits) for 5 drones.

Figures are saved in `results/`: example paths, the animated GIF, EDA plots, metric comparisons, scalability and the QUBO matrix.

## 7. Limitations and possible improvements

- Prioritized planning is **incomplete** and **not optimal**: a bad priority order can block a drone in a narrow corridor. Possible fixes are random restarts or Conflict-Based Search (CBS).
- The QUBO can only choose among the candidate paths it receives, and it is sensitive to the penalty weights `A` and `B` (studied in notebook 03).
- The model is simplified: a 2D discrete grid, constant speed, no flight dynamics, no uncertainty and perfect centralised communication.
- Possible extensions include a 3D airspace, decentralised coordination, iterative candidate generation (column generation, as in Gerlach et al., 2025), and running the same `Q` matrix on a quantum annealer through D-Wave Ocean.
